# 项目组合看板 · 本地复刻

打开 `index.html` 或 `项目组合看板.html` 即可使用；所有样式、脚本、四个项目数据均内联，不依赖网络、不需安装软件。

需要 HTTP 预览时，在本目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8766/index.html`。这只是本机预览，不是公网地址。

- 点击项目卡片进入全页详情；点击卡片内“预览 ↗”打开详情弹窗，支持 Esc 关闭和“全页查看”。
- 底部支持状态筛选、搜索，以及 DOD / 完成度 / 未结风险 / 名称排序。
- 详情支持二期里程碑切换、风险筛选、计划/实际日期和偏差徽章、团队、日志、DOD 解释。
- 设置面板支持快速跳转、紧凑模式和减少动效。
- 浏览器前进/后退、刷新及 `#/p/项目名` 深链接均可使用。

## 文件

- `index.html`：主交付，单文件网页。
- `项目组合看板.html`：同内容的中文命名附件，便于转交下载。
- `projects.json`：从最终页面导出的完整四项目数据。
- `reference/`：只读线上源码、此前简版页面、五份用户知识文件。
- `verification/`：真实 Chrome 截图及 `results.json` 验证记录。
- `build.py`：从参考快照生成本地复刻，可重复执行。
- `verify.cjs`：交互和布局回归检查。使用本机现有 playwright-core 和 Chrome；路径写在脚本中，跨机器运行需调整，交付 HTML 不受影响。
